Imperium Drive Privacy Policy

Last updated: September 28, 2026

Imperium Drive is a personal tool. Its only user is its owner.

What it accesses

With the owner's consent, it accesses the owner's own Google Drive, Docs, Sheets, Slides and Calendar data through Google's APIs.

How the data is used

The data is used only to carry out tasks the owner asks for on the owner's own computer. It is not sold, shared, or transferred to any third party, and it is not used for advertising.

Storage

Login tokens are stored only on the owner's computer. No data is kept on any server run by this tool.

Google API data

Use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions.
